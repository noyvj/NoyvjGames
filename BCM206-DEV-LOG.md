The clearest cross-cutting infra lesson from this pass: three separate games' audits (SOL, Aftermath, and — in a non-coursework game — Continuum) independently found the same *class* of save-system bug: a save/load path that works for "same build, same session" but silently corrupts or crashes on "load a save written by an older or newer build than the one currently running" (a wholesale dict-replace stomping keys the current build expects but an older save doesn't carry, or vice versa).

# Dream game: puzzle ideas for each building

Written 2026-10-09 because you asked for "a bunch of ideas for each that I can pick between" (FOR-YOU Fg12). Every building in the dream game has its own puzzle whose levels give that building permanent upgrades. Each item is one puzzle idea for one building: "yes" picks it as a candidate, "later" parks it, "no" drops it. You can say yes to several per building; I will build the ones you pick as their own small game first (Fg3). All are quiet, fixable and timer-free. The building list is a starting set; add or rename any in a comment.

## BU. Builder's workshop (the first building; keeper: the builder)

1. **[SMALL]** Joinery: fit differently shaped timber pieces into a frame outline with no gaps; each solved frame unlocks a new building type.
2. **[SMALL]** Blueprint balance: place beams so the load on every support stays under its limit; a good result gives sturdier buildings.
3. **[SMALL]** Cut list: cut planks from a log to fill a list of orders with the least waste.
4. **[SMALL]** Scaffold climb: build a path of plank pieces from the ground to a roof gap within a fixed number of planks.
5. **[SMALL]** Tool tidy: sort tools into a rack by size and use so everything fits; a tidy rack makes building faster.
6. **[BIG]** Floor plan puzzle: lay out rooms inside a building outline so every room touches the doors and light it needs.

## SA. Sawmill and woodcutters (wood gathering; Canopy links here by achievement buff only)

1. **[SMALL]** Log stack: stack uneven logs so the pile does not tip, using a simple balance rule.
2. **[SMALL]** Grain reading: match a cut's ring pattern to the right tool and angle.
3. **[SMALL]** Sorting belt: route logs by type on a short conveyor with switches.
4. **[SMALL]** Replanting map: choose where to replant so the forest edge keeps a clear path to the cabin.
5. **[SMALL]** Sharpening: line up a blade's angle by feel (a dial and a visible sparks gauge, no timer).
6. **[BIG]** Forest survey: reveal and mark trees on a fog grid using clues from neighbouring counts (a minesweeper-like deduction).

## MI. Mine and bunker (mining mode, separate screen)

1. **[BIG]** Vein deduction: numbers on the edges show how much ore lies in each row and column; find the veins (a nonogram-style puzzle).
2. **[SMALL]** Shoring: place supports so no tunnel span is too long.
3. **[SMALL]** Cart routing: lay track from the face to the lift with turns and switches.
4. **[SMALL]** Ventilation: connect fans and shafts so air reaches every working room.
5. **[SMALL]** Assay: weigh samples on a balance to find the odd one.
6. **[BIG]** Bunker rooms: open sealed bunker sections by solving each door's lock (logic, symbols or sequences) to unlock a specialisation.

## LI. Library and records

1. **[SMALL]** Catalogue sort: shelve books by clues about author, colour and subject.
2. **[SMALL]** Torn page: rejoin torn pieces of a page by edges and content.
3. **[SMALL]** Cipher margin: decode notes with a key hidden in another book.
4. **[SMALL]** Reading order: put a set of letters and journals in the order they must have been written, from the details inside them.
5. **[BIG]** Family tree: fill a tree from scattered records; a completed tree unlocks that family's quest.
6. **[SMALL]** Map restoration: place map fragments by matching coastlines and roads.

## WO. Workshop and robotics bench (research to robots)

1. **[BIG]** Circuit bench: build a working circuit from parts to light, move or sense something.
2. **[SMALL]** Gear train: connect gears so the output turns at the required speed and direction.
3. **[SMALL]** Part salvage: take apart a broken machine into the right parts in the right order.
4. **[SMALL]** Calibration: match a gauge reading by adjusting several linked knobs.
5. **[BIG]** Assembly line: arrange stations on a belt to turn parts into a product at the lowest cost (the production line that leads to robots).
6. **[SMALL]** Wiring diagram: reconnect a tangled board by following a schematic.

## FA. Farm and greenhouse

1. **[SMALL]** Crop rotation: plan which crop goes in which bed over seasons so the soil recovers.
2. **[SMALL]** Watering paths: lay channels to reach every bed with limited pipe.
3. **[SMALL]** Seed matching: pair seeds to beds by light, soil and season clues.
4. **[SMALL]** Frost cover: place covers on beds so every tender plant is covered with the fewest sheets.
5. **[SMALL]** Pollination: guide a few bees through flowers in an order that reaches all of them.
6. **[SMALL]** Preserving: pack jars into a shelf so they fit and can be reached.

## AP. Apothecary and kitchen

1. **[SMALL]** Recipe mix: combine ingredients to reach a target taste or effect (add and balance sliders).
2. **[SMALL]** Label the shelf: deduce which herb is which from smell, colour and use clues.
3. **[SMALL]** Boil down: reduce a liquid to an exact amount by choosing heat steps.
4. **[SMALL]** Pantry fit: pack a larder so the most-used items sit in reach.
5. **[SMALL]** Feast plan: plan courses for guests with likes and dislikes (links to gifting).
6. **[BIG]** Remedy book: discover recipes by combining clues from keepers about what ails them.

## OB. Observatory and radio tower

1. **[SMALL]** Star map: connect stars into a named pattern by rules.
2. **[SMALL]** Tuning: find a station by adjusting two dials against a signal-strength meter.
3. **[SMALL]** Decode: turn a repeating signal into a message (binary, Morse-like or glyphs).
4. **[SMALL]** Aiming: line up a dish with a moving source using stepped turns.
5. **[SMALL]** Lens alignment: stack lenses so a beam reaches a sensor.
6. **[BIG]** Sky catalogue: match observations from different nights to find what moved.

## TA. Tavern and meeting hall

1. **[SMALL]** Seating plan: seat guests so likes and dislikes are respected.
2. **[SMALL]** Story order: arrange a told story's events using clues from several tellers.
3. **[SMALL]** Who said it: match statements to speakers from a few hints.
4. **[SMALL]** Table game: a small two-player-style logic game against the keeper, solvable without luck.
5. **[SMALL]** Song lines: reorder scrambled lines of a verse by rhyme and rhythm marks.
6. **[SMALL]** Rumour chain: trace which rumour started where from who told whom.

## SM. Smithy and metalwork

1. **[SMALL]** Heat colours: pick the right heat step for each stage of a piece.
2. **[SMALL]** Alloy mix: blend metals to hit target numbers.
3. **[SMALL]** Mould fit: choose a mould that fills without gaps from a few pieces.
4. **[SMALL]** Forging order: put steps in the right order to avoid cracking (rules shown).
5. **[SMALL]** Rivet pattern: place rivets so a plate holds with the fewest.
6. **[SMALL]** Repair puzzle: mend a broken tool by fitting back its fragments.

## HE. Healer's hut and shrine

1. **[SMALL]** Herb drying: arrange racks so each herb gets the light and air it needs.
2. **[SMALL]** Symptom match: deduce what ails a visitor from signs (invented conditions, no real medical advice).
3. **[SMALL]** Bandage wrap: a path puzzle where the wrap must cover a shape without overlap.
4. **[SMALL]** Candle ritual: light candles in an order that follows a pattern of rules.
5. **[SMALL]** Garden of remembrance: place stones and plants by clues about those remembered.
6. **[SMALL]** Dream lines: connect matching symbols in a sleeping visitor's dream without crossing.

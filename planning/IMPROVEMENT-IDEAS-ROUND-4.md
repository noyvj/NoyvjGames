6. **[SMALL]** Add a trade map in the Overview showing which worlds ship what to which, with thicker lines for bigger flows. You see the whole economy at a glance instead of opening each route.
7. **[SMALL]** Add a soft early warning when ecology is heading toward the penalty zone at the current rate ("Ecology reaches 10% in about 40 ticks") with the cheapest fix suggested. You can prevent trouble instead of reacting to it.
8. **[SMALL]** Show "affordable in about N seconds" next to every Buy button, based on current income. You can plan purchases instead of watching numbers.
9. **[SMALL]** Add a hover preview on each world in the Overview showing what finishing its terraforming will unlock. You can choose which world to focus on for a reason.

12. **[SMALL]** Add a "status in three sentences" button that describes the whole system in plain words (which worlds are running, what is short, what is next). Screen reader users and tired players get the full picture without scanning every card.
13. **[BIG]** Add handcrafted rescue worlds: short puzzle scenarios such as "Ceres starts with no water and 5% ecology; bring it above 50% using only six buildings". You get a set of finite puzzles with clear finish lines inside the incremental game.
14. **[SMALL]** Add a Buy x1 / x10 / Max stepper beside building purchases, with the total cost shown before you click. Late-game shopping gets faster and clearer.
15. **[SMALL]** Add interface colour themes named after worlds (Mars rust, Venus amber, Neptune blue), each unlocked when you finish that world. You get a cosmetic reward for every world you complete.

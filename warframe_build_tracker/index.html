Warframe Build Resource Tracker

Zaws • Kitguns • Amps

How it works: enter how many component parts you already own, then enter your raw/refined resource inventory below. The tracker calculates what is still required. Recipes are hand-curated from the WARFRAME Wiki (each part's Wiki page has a direct link below) rather than fetched live — see README.md for why. Sign in above to save your progress to your account (cross-device) — or just play anonymously and use the Save button below, same as any other game on the hub.
Import from a real inventory snapshot (optional): if you've run warframe-api-helper or AlecaFrame, you'll have a lastData.dat (or inventory.json) file — upload it below to auto-fill your resource "built" counts from your real in-game inventory instead of typing them by hand. Everything happens in your browser; the file is never sent anywhere. This matches resource names by the tail end of their internal game path, so it's a best-effort match, not guaranteed exhaustive — the summary after uploading tells you exactly what did and didn't match, so you can fill any gaps manually. Only resource "built" counts are touched; part-owned counts and "raw" amounts are untouched, since a built component isn't tracked as a standalone countable item in Warframe's own data.

About Signal

Signal is a small daily deduction puzzle set in a retro radio room. Everyone gets the same board each UTC day. It teaches nothing and needs no account.

  • Every puzzle is generated from its date, offline, and checked by a solver so there is always a way to find the answer within your pings.
  • Par is how many pings a greedy solver needed. It is an upper bound on the true minimum, so beating it is possible.
  • The signal rule is invented for this game: a transmitter's strength at a tile is max(0, radius minus the Manhattan distance). It is not a model of real radio propagation.
  • Streaks count wins on the daily puzzle only. Archive and practice never touch them.
  • The leaderboard, if you opt in, shows your longest daily streak. Scores are reported by your browser, so it is a friendly board, not an anti-cheat one.
  • Puzzles are generated in your browser by Python running in WebAssembly (Pyodide). The board draws instantly; the first ping of a cold visit waits for that engine to finish loading.

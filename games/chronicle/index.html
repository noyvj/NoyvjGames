    About Chronicle

    Chronicle is a history game built from sets. A set is a folder of data: events, people, places and claims, so a new topic is new data, not new code. Today there is one sample set, the American presidency.

    • Every fact the game shows is a claim, and every claim links at least three reputable sources from at least two institutions. Each source gives its title, who published it, a link, and the date it was read.
    • Claims carry a confidence label, always written out and marked with a symbol, never colour alone. ✔ Documented: sources agree. ≈ Disputed: reputable sources differ, so the game shows each position. ? Traditional but doubtful: a popular story the sources do not support. Myth or record is built from exactly this label.
    • A cause link is a claim too, so it has the same three sources and the same confidence label, plus a strength: ⇒ Direct cause (the sources treat it as the immediate trigger) or ⇢ Contributing cause (one factor among several). Causes are plural, so no link is ever presented as the whole story.
    • Whose account? shows short passages about one event from different sources. Each passage is a summary written for this game in original words, tied to one real source (a primary source made at the time, or a secondary one written afterwards). You say who wrote it, what the writer could see, what the writer was trying to do, and what the passage leaves out. "Leaves out" is judged against the short passage you read, never against the whole source, and the full source is always one link away.
    • Decision points show a choice a historical figure really faced, only where the sources document the options. You choose; nothing is graded. The game then shows what they chose and what the sources say followed, always labelled as what they chose. It never presents an alternative as what would have happened.
    • Review brings back what you have learned after gaps of 1, 3, 7, 14 and 30 days. Days only move when you press Let a day pass, so there is no clock, no deadline and nothing that runs out while you are away. A fact you do not recall returns tomorrow and is never taken away.
    • All text is original wording; only facts are reused. All art is drawn by code. No images are generated.
    • The sample set was drafted by an AI assistant from sources it read on 7 October 2026 and is a draft until the owner has reviewed it. If a claim looks wrong, use Report a problem beside it. Reports open soon: for now a report is only saved on this device.
    • The presidents sets aim to be balanced and non-partisan: each moment is stated as a dated, sourced fact, not as praise or blame.

      Cause web

      Which moment helped lead to which? Pick the earlier moment (the cause), then the moment it led to. The game confirms a thread only if this set's sources link the two, and says how strong the evidence is. Most moments have several causes, so a moment can end more than one thread. Moments are listed earliest first.

        Threads

          Myth or record

          Sort each statement into the bin that says how sure the sources are. Press Check when every statement has a bin: the right ones lock, and when all are right you see why, from the sources themselves.

              Whose account?

              Each passage below is a short summary, written for this game in original words, of one real source about the same event. The questions are about the passage marked with a diamond. Pick an answer for each question, then press Check: right answers lock, and when all are right you see the sources. "Leaves out" means not in the short passage you read.

                  Decision points

                  A choice someone really faced, shown only where the sources document the options. Pick what you would do. Nothing is graded: afterwards the game shows what they chose and what the sources say followed.

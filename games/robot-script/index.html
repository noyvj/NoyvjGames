Robot Script

Write the robot a short list and watch it clear the room. Nothing is timed, and a wrong run only costs you a retry.

Rooms

A chapter opens once five rooms of the one before are cleared. Inside a chapter, play any room in any order. The medal on a room is for the shortest list you have cleared it with.

Workshop

Each room you clear gives Scrap one part. A better list gives a better finish on the same part: rusted, clean, polished. Nothing is missable.

      How the list works
      
                      
        
                    • Tap an instruction to add it where the marked gap is. Tap another gap to add somewhere else. The x on a step removes it.
                      • 
        
                    • The robot does the steps top to bottom. If a step cannot be done (a wall, a shut door, nothing to pick up), the run stops there, shows why, and your list is untouched.
                      • 
        
                    • Fewer instructions earn better medals: every instruction, repeat, branch and call counts as one step.
                      • 
        
                    • Keyboard: F, L, R, G, P, S add that instruction; Backspace removes the step before the gap; Z undoes; Enter runs.

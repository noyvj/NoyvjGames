How it is made

NoyvjGames is a personal portfolio of small game demos built by one person together with an AI coding assistant, Claude from Anthropic. The AI wrote and reviewed much of the code; the ideas, the decisions and what ships are the site owner's. The full story of how the site grew is in the public source on GitHub, and each change is listed in What's New.

Running the games

  • Pyodide (version 0.26.4), which runs Python in your browser through WebAssembly. Every game's rules are written in Python and run this way. It is loaded from the jsDelivr content network.
  • Python itself, for the games, the backend and the small scripts that keep the site's lists up to date.
  • three.js (version r128), used by Continuum for its low-poly 3D scenes, loaded from jsDelivr. Continuum falls back to a flat 2D view when WebGL is unavailable.
  • Everything else on screen is plain HTML, CSS and JavaScript with no build step and no front-end framework.

Hosting and the server

  • GitHub Pages hosts the site you are reading.
  • The ratings, accounts and save-code API is written with FastAPI, SQLAlchemy and Pydantic, runs on FastAPI Cloud, and keeps its data in a Neon Postgres database.
  • The tests that guard both the site and the backend run on pytest.
  • The ad bar is built for Google AdSense, but it is a placeholder and shows no live ads. See Terms & Privacy.

Fonts, pictures and icons

  • Fonts: none are downloaded. The site uses the fonts already on your device (your system's default interface font), so there is nothing to credit and nothing extra to load.
  • Game pictures: each title card's picture is a small scene drawn in CSS for that game, not an image file and not generated imagery.
  • Icons: each game's browser-tab icon is a simple shape and letter made for this site. The hub's own app icon is placeholder art.
